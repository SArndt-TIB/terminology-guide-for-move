# Workflow: CSV-RDF-Mapper

> :warning: Der CSV-RDF-Mapper Workflow ist noch nicht voll funktionsfähig! Wir arbeiten noch daran!

In den folgenden Abschnitten erläutern wir Ihnen das Tool CSV-RDF-Mapper und wie sie es nutzen können, um tabellarische Daten damit in ein [RDF][RDF]-Vokabular umzuwandeln.
Hierzu stellen wir auch tabellarische Vorlagen sowie eine Mappingdatei zur Verfügung, die Sie direkt für ein zweisprachiges Vokabular nutzen können, das den SKOS-Standard befolgt.

## Software-Requirements

Sie benötigen keine spezielle Software, sondern lediglich einen Webbrowser. Der [CSV-RDF-Mapper](../../../tools_SKOS-CSV-RDF-Mapper.md) ist ein Webservice.
Wir empfehlen allerdings die Nutzung von Google Chrome.

## Benötigte Dateien

Natürlich benötigen Sie zunächst einmal ein nach unseren [Vorlagen](tutorial-4.md) aufbereitetes Vokabular mit Ihren eigenen Daten.
Zur Transformation nach [RDF][RDF] benötigen Sie darüber hinaus eine Transformationsdatei für CSV-RDF-Mapper von unserem GitHub-Repositorium - bitte laden Sie hier [termshape.ttl](https://raw.githubusercontent.com/SArndt-TIB/terminology-guide-for-move/refs/heads/develop/CSV-RDF-Mapper_Templates/termshape.ttl) vorab herunter.

[RDF]: ## "Resource Description Framework"
