# Schritt 4 - Die Wahl einer Lizenz

Um Ihre Terminologie für andere möglichst leicht nachnutzbar zu machen, sollten Sie klar kommunizieren, welche Lizenz für die Terminologie vergeben und welche Berechtigungen Sie den Nutzern einräumen.

Damit Ihre Terminologie als offen und FAIR gelten kann, ist die Vergabe einer offenen Lizenz erforderlich.
Hier empfehlen wir Ihnen die Wahl einer Lizenz, die die [Open Definition](https://opendefinition.org/od/2.1/en/) erfüllt.
Eine Liste dieser Lizenzen finden Sie [hier](https://opendefinition.org/licenses/).

Für eine Creative-Commons-Lizenz kann man auch den [License Chooser](https://chooser-beta.creativecommons.org/) verwenden, der bei der Auswahl einer geeigneten Lizenz unterstützt.

Sollten Sie Fremdmaterialien verwenden, beachten Sie bitte das Urheberrecht und gültige Regelungen.
Klären Sie die Vergabe einer offenen Lizenz im Einzelfall vorab.
