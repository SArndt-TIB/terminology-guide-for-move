# Schritt X - Die Wahl einer Lizenz

Um Ihre Terminologie für andere möglichst leicht nachnutzbar zu machen, sollten Sie klar kommunizieren, welche Berechtigungen Sie auf dem von Ihnen erstellten Material zulassen.

Damit Ihre Terminologie als offen und FAIR gelten kann, ist die Vergabe einer offenen Lizenz erforderlich.
Hier empfehlen wir Ihnen die Wahl einer Lizenz, die die [Open Definition](URL ergänzen) erfüllt. Eine Liste dieser Lizenzen finden Sie [hier](URL ergänzen).

Wenn Sie sich bei der Wahl der Lizenz unsicher sind, hilft hier gegebenenfalls auch ein Entscheidungsbaum.
