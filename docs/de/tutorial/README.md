# Übersicht

Mit unserem Tutorial wollen wir Ihnen hilfreiche Tipps, Werkzeuge und Methoden an die Hand geben, mit denen Sie selbst eine terminologische Ressource für das Semantic Web erstellen und publizieren können.
Das Tutorial soll Sie dabei in allen Phasen des Lebenszyklus eines Vokabulars begleiten - von der Konzeption bis zum End of Life.
Gleichzeitig unterstützen wir Sie dabei, Ihre Ressource nachhaltig zur Verfügung zu stellen und FAIR zu machen.
