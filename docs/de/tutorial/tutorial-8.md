# Vokabular veröffentlichen+

In unserem Tutorial verfolgen wir einen Kurs der offenen Entwicklung des Vokabulars.
Mit unserer Anleitung richten Sie bereits sehr früh eine Arbeitsumgebubg ein, aug der der Code der Terminologie offen bereitgestellt wird und in der eine Mitwirkung durch Externe potentiell möglich ist.

Über diese öffentliche Bereitstellung hinaus, haben Sie quch weitere Möglichkeiten, Ihre Terminologie zu verbreiten und zu archivieren.

Wir empfehlen zum Beiapiel die Archivierung auf [Zenodo](URL einfügen).
Dadurch erhalten Sie zusätzlich zu den von Ihnen eingerichteten Identifiern für das Vokabular eine DOI.

* Bartoc
* Terminology Services
* FAIRSharing.org
* LOV
