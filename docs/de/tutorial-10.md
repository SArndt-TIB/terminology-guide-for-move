# Tabellenvorlage für das Tool OpenRefine

Für die Nutzung mit dem Tool [OpenRefine](tools_OpenRefine.md) haben wir eine Vorlagen erstellt. Sie dient der Sammlung von

* Begriffen und ihren Fachausdrücken,
* Quellenangaben,
* Autoren, sowie
* Querbezügen zwischen diesen Entitäten.

## Struktur der Tabelle und Erläuterung der Spalten

Mit der Tabelle sollen wie bereits gesagt verschiedene Entitäten in einem Blatt erfasst werden. Informationen zu einem Emtitätentyp können auf mehrere Zeilen verteilt sein, denn jede Zelle darf immer nur einen einzigen Wert enthalten. Von der Verwendung von Binnentrennzeichen raten wir an dieser Stelle ab! Durch die Verwendung mehrerer Zeilen für dieselbe Entität kann ein großer Teil der Zellen leer bleiben.

### Erläuterung der Spalten

|Spalte|Erläuterungen|

|**Type**|**Erlaubte Werte:** `Concept` `Source` `Author`<br><br>**Definition:** Da in der Tabelle die Entitätentypen _Begriff_, _Quellennachweis_ und _Verfasser_ aufgenommen werden, wird in der Spalte _Type_ die Art des Entitätentyps ausgewählt, die in der Zelle beschrieben wird.<br><br>**Hinweise:** Sofern das Format es zulässt, sind die Zellen mit einem Drop-down-Menü hinterlegt, sodass schnell einer der zulässigen Werte gewählt werden kann. Die Information sollte für jede Zeile angegeben werden, da die Spalte die Filterung und Gruppierung der Daten sowie eine Erstellung von Ansichten erlaubt.|
|**Verfasser - ID**|**Beispielwerte:** `Author1` `Author2`<br><br>**Definition:** In dieser Spalte muss eine lokaler Identifier für die beschriebene Person angegeben werden.<br><br>**Hinweise:** Wir empfehlen, den Identifier aus einer Kombination von Typname (hier `Author`) und einer forlaufenden Nummer (z.B. `1`) zu erstellen.<br>Falls Sie ausschließlich eine Nummer verwenden möchten, achten Sie bitte darauf, dass sich die Nummern in den anderen ID-Spalten nicht wiederholen dürfen (also in `Begriff - ID` und `Quellennachweis -ID`).<br>Jede Tabellenzeile, die einen Verfasser beschreibt **muss** in dieser Spalte einen **korrekten** Wert enthalten, damit die Tabelle später korrekt ausgelesen werden kann.<br><ul><li>Fehlt die ID in allen Zeilen, die den Verfasser beschreiben, kann kein Eintrag für diesen Verfasser erstellt werden.</li><li>Fehlt die ID in einer oder mehreren Zeilen wird ein unvollständiger Eintrag erstellt, dem dann die Informationen der jeweiligen Zeilen fehlen.</li><li>Wird in einer Zeile nicht die ID der zum selben Verfasser gehörigen Zeilen angegeben, wird die Information der jeweiligen Zeile in einen eigenen Eintrag übernommen.</li><li>Wird in einer Zeile eine ID angegeben, die bereits für einen anderen Verfasser gesetzt wurde, werden die Informationen unterschiedlicher Verfasser in einen Eintrag zusammengeführt!</li></ul>|
