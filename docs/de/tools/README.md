# Tools

Zum Erarbeiten und Arbeiten von und mit RDF-Vokabularen gibt es eine große Menge verfügbarer Tools, die mehr oder weniger einfach zu nutzen sind.
In diesem Tutorial setzen wir vor allem auf Tools, die für die meisten Menschen bereits verfügbar oder leicht zu nutzen sind und mit denen sie bereits eine gewisse Vertrautheit haben.
Bei Tools für speziellere Aufgaben lässt sich der Einsatz speziellerer Tools leider nicht ganz vermeiden.
Hier versuchen wir dann aber insbesondere Webservices zu nutzen, die über einen Browser bedient werden können.
Wir versuchen, die Installationsaufwände möglichst gering zu halten.

Wir stellen Ihnen in diesem Tutorial eine Reihe von Tools vor, die Sie bei

* der Recherche von Terminiologie unterstützen,
* die Erstellung von RDF-Vokabularen ermöglichen,
* die Prüfung solcher Vokabulare erlaubt,
* ihre Veröffentlichung und Zitierbarkeit unterstützen.
