# SKOS Play

SKOS Play ist ein Webservice, der unter <https://skos-play.sparna.fr/play/home> erreicht werden kann.
Er unterstützt verschiedene Aufgaben:

* die Generierung von [Dokumentation](../../tutorial/tutorial-1.md) aus SKOS-Vokabularen
* die [Konvertierung](../../tutorial/step-5/tbd) von Excel-basierten Vokabularen in RDF-Vokabulare basierend auf dem SKOS-Standard
* die [Qualitätsprüfung](../../tutorial/tutorial-9.md) von Vokabularen nach bestimmten SKOS-bezogenen Qualitätskriterien
